烏山頭水庫遊戲包
==================

內容：
- index.html
- styles.css
- script.js
- assets/ 圖片素材

開啟方式：
1. 直接雙擊 index.html 可本機預覽。
2. 或將整包上傳到網站空間 / GitHub Pages / Netlify / Vercel。

這版調整：
- 角色視覺更靠近你提供的照片（直接使用照片裁切作為角色卡）
- 強調地點為「烏山頭水庫」
- 拆完後增加完成回饋畫面（Mission Complete Overlay）
- 版型改得更接近你提供的地圖網站：大地圖 + 側邊資訊面板 + 地圖亮點互動

備註：
- 目前角色是「更像照片」的做法，不是真正 3D 建模角色。
- 地圖為創意化互動視覺，不是精準真實 GIS 圖。
